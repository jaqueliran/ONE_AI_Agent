# ONE_AI_Agent
Processo de elaboração de IA agêntica capaz de responder perguntas corretamente consultando documentação pré-determinada. 
Programa ONE (Oracle Next Education) AI for Tech + Alura. 
Este é o agente da escola  de inglês fictícia _Common Ground_ e responde acessando documentos acadêmicos, pedagógicos e operacionais da instituição.
